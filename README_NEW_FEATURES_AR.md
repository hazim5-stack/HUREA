# إضافات HUREA

تم تطوير حزمة Extensions v1 لتوفير 14 أداة إضافية عبر CLI وMCP.

| المجال        | الموجود في هذه النسخة                                                                                          |
| ------------- | -------------------------------------------------------------------------------------------------------------- |
| Frida         | مراقبة الوحدات والخيوط، تتبع الدوال وCall Stack، قراءة ذاكرة محدودة، مراقبة JNI، وجسر Objective-C قابل للترجمة |
| LLDB          | فحص العملية وتتبّع Breakpoints خلال فترة محددة، ثم فصل المصحح                                                  |
| Android       | تحليل محتويات APK، قراءة Manifest بواسطة aapt2، فك Java بواسطة JADX، وفحص صادرات JNI                           |
| iOS           | Info.plist وEntitlements وملف Provisioning وموارد الواجهة المصدرية وقائمة الرموز                               |
| تدفق البيانات | بناء رسم من SSA IR للدوال والمعاملات وقيم الإرجاع، وتتبع العلاقات للأمام والخلف                                |
| الشبكات       | HAR ومخططات JSON ومقارنة المسارات، بيانات PCAP، وسوم protobuf، والتقاط شبكة محدود                              |
| مقارنة الدوال | بصمات التعليمات والثوابت والنصوص والعلاقات ومطابقة المرشحين بين نسختين                                         |
| واجهة الأدلة  | رسم تفاعلي محلي مع تصفية وعرض مصدر الثقة والقيود                                                               |
| نظام الإضافات | تعريف Provider محلي وتسجيله وتشغيل عملياته المصرح بها                                                          |
| Firmware      | اكتشاف بصمات الأنظمة والملفات، وتشغيل Binwalk وقائمة SquashFS                                                  |
| أدوات التحليل | موصلات LIEF وRizin وBinary Ninja وIDA وHex-Rays المتاح لديك                                                    |

هذه النسخة تنفذ تغطية أولية لهذه المجالات. لا تعني استرجاع الكود الأصلي أو تصميم SwiftUI تلقائيًا، ولا حل جميع أنواع JNI أو تدفق البيانات من أي ملف ثنائي دون IR.
الأدوات الخارجية والتراخيص والأجهزة غير مرفقة؛ يلزم توفيرها لتشغيل موصلاتها.

للتشغيل والتفاصيل: `docs/extensions.md`.
لنتائج الاختبارات وحدود التحقق: `docs/EXTENSIONS_VALIDATION.md`.

```bash
npm ci
npm run build:cached
node scripts/hurea.mjs extensions inspect_extension_providers -
```

كل عملية لها ملف JSON للمعاملات. على سبيل المثال:

```json
{ "path": "/absolute/path/App.ipa", "mode": "bundle" }
```

```bash
node scripts/hurea.mjs extensions inspect_ios_package request.json
```
